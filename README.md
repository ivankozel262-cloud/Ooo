# Система

Живой механизм наблюдения: неизменное ядро, сменные миссии и органы. Он собирает данные, сохраняет их, находит важное и сообщает. Весь код пишет Claude Code.

## Где мы сейчас

**Сезон 1 «Росток».** Готовы этапы 0 и 1: ядро работает, миссия «Планета» собирает землетрясения. Следующий — этап 2: рентген-дерево.
Подробно — в [docs/progress.md](docs/progress.md).

## Устройство папок

| Папка | Что внутри |
| --- | --- |
| `core/` | Ядро: реестр плагинов, шина событий, планировщик, хранилище |
| `plugins/` | Органы: сборщики, обработчики, детекторы, выходы |
| `missions/` | Миссии: что отслеживать (файлы `.yaml`) |
| `brain/` | Мозг: Claude, локальная модель или без AI |
| `builder/` | Строитель: отсюда система зовёт Claude Code править свой код |
| `memory/` | Память опыта: нормы, исходы, похожие случаи |
| `xray/` | Рентген: живая схема-дерево в браузере |
| `reports/` | Входящие: сигналы и отчёты |
| `migrations/` | Обновления базы без потери данных |
| `tests/contracts/` | Проверки, которые проходит любой модуль |

В git не хранятся `data/` (база), `backups/` (копии), `chronicle/` (кадры и видео) и `.env` (ключи). Они живут только на компьютере.

## Как открыть на MacBook

Один раз, в «Терминале»:

```bash
cd ~
git clone https://github.com/ivankozel262-cloud/Ooo.git sistema
cd sistema
claude
```

Попробовать Систему (нужен [uv](https://docs.astral.sh/uv/): `curl -LsSf https://astral.sh/uv/install.sh | sh`):

```bash
uv run sistema run planet        # собрать землетрясения за последний час
uv run sistema events --last 1h  # показать, что собрано
uv run sistema serve             # работать постоянно, раз в минуту (Ctrl+C — стоп)
```

Потом, чтобы забрать свежие изменения с GitHub:

```bash
cd ~/sistema
git pull
```
