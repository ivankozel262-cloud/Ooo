## Что уже умеет Система
- Принимать события единого формата (`core/event.py`) и хранить их в `data/sistema.db` без дублей.
- Сама находить плагины в `plugins/` и запускать миссии из `missions/` по расписанию.
- Миссия «Планета»: землетрясения со всего мира из USGS раз в минуту.
- Команды: `uv run sistema run planet`, `uv run sistema events --last 1h`, `uv run sistema serve`.
- 70 тестов, сеть в них выключена; тесты-контракты — в `tests/contracts/`.

## Как проверить на маке
```bash
cd ~/sistema && git pull
uv run sistema run planet
uv run sistema events --last 1h
uv run pytest
```

## Заметки
- Облачный контейнер, где идёт работа, не пускает к сайту USGS. Поэтому сборщик проверен на образце ответа, а настоящие землетрясения появятся при первом запуске на маке.
- `sistema snapshot` ещё нет: он появится на этапе 3.
